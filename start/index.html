Персональная лаборатория данных для обучения

Полнофункциональная среда для изучения анализа данных, машинного обучения и работы с большими данными. Всё необходимое уже настроено и готово к работе — просто запустите Docker и начните экспериментировать.

📃 Инструкции и исходники

JupyterLab

Интерактивная среда для экспериментов с данными и кодом на Python. Создавайте и запускайте ноутбуки, редактируйте файлы, работайте с терминалом — всё в одном месте. Идеально подходит для анализа данных, прототипирования и обучения.

🚀 Открыть JupyterLab 📚 Документация

Apache Spark (PySpark)

Платформа для распределённой обработки больших объёмов данных. Используйте PySpark для анализа датасетов любого размера, выполнения SQL-запросов, построения data pipelines и потоковой обработки. Полностью интегрирован с JupyterLab.

📚 Документация

MinIO Object Storage

Локальное объектное хранилище с S3-совместимым API. Храните датасеты, результаты обработки и любые файлы. Управляйте данными через веб-интерфейс или подключайтесь программно из Python, используя стандартные S3-клиенты.

🎛️ MinIO Console 📚 Документация

🔐 Учётные данные:

Access Key: minioadmin Secret Key: minioadmin

📡 API Endpoint:

http://localhost:9000

PostgreSQL 18

Предустановленная реляционная база данных для хранения учебных датасетов, промежуточных результатов и артефактов экспериментов. Подключайтесь из Jupyter ноутбуков, BI-инструментов или любых SQL-клиентов — сервис уже запущен и проброшен на хост.

📚 Документация

🔐 Учётные данные:

User: postgres Password: postgres DB: postgres

🔌 Подключение с хоста:

localhost:6432 postgresql://postgres:postgres@localhost:6432/postgres

💡 Пример:

psql -h localhost -p 6432 -U postgres
